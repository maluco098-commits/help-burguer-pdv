- assets/logo-help-burguer.png: logo fornecida.

COMO USAR
1. Abra/crie seu projeto no VS Code.
2. Copie o conteúdo de prompt-help-burguer-pdv.txt para o agente de programação (Copilot/Cline/Roo Code/Cursor ou similar).
3. Mantenha a pasta assets dentro do projeto.
4. Peça para a IA seguir as etapas do prompt e implementar o sistema de verdade.
5. O prompt foi escrito para exigir banco de dados, backend, frontend, impressão térmica e integração preparada para WhatsApp.

IMPORTANTE
As imagens são referências visuais. O prompt exige implementação funcional, não apenas um mockup.
